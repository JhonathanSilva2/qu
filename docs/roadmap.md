# Roadmap

| Patch | Resultado |
| --- | --- |
| 00 — Fundação | Projeto Fabric 1.21.10, configuração, logs, entidade registrável e comando de invocação. |
| 01 — Entidade | Atributos, movimento próprio, aparência e persistência explícita. |
| 02 — Percepção e navegação | Protótipo de seguimento controlado por comando; evoluir para detectar árvores, baús, recursos e ameaças e alcançar alvos sem loops infinitos. |
| 03 — Decisão | Objetivos/prioridades, estados e tarefas com cancelamento, retomada e falha. |
| 04 — Madeira | Localizar árvore, coletar blocos e recolher os drops. |
| 05 — Armazenamento | Inventário, localizar baú e depositar madeira; tratar capacidade e falhas. |
| 06+ — Sobrevivência e sociedade | Necessidades, profissões, cooperação e assentamentos. |

O MVP de produto (um NPC que coleta e armazena madeira) atravessa os patches 00–05. O Patch 00, isoladamente, é só a primeira fatia técnica, não o MVP completo.
